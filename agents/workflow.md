# Workflow: стандартный цикл разработки

Каждый шаг выполняется отдельным суб-агентом.
Промпт агента берётся из файла шага (поле «Промпт»), имя файла = имя шага.

## Правила оркестрации

- Шаги выполняются строго по порядку: 01 → 02 → 03 → 04.
- Результат предыдущего шага передаётся следующему в блоке «Контекст от предыдущего шага».
- Если шаг завершился со статусом FAIL — workflow останавливается, ошибка передаётся пользователю.
- Шаги из секции «Параллельно» можно запускать одновременно (здесь таких нет).

## Шаги

| # | Файл агента | Роль | Выход (в формате) |
|---|-------------|------|-------------------|
| 01 | 01-analyzer.md | Анализирует задачу и кодовую базу, план | План изменений: файлы, подход, риски |
| 02 | 02-implementer.md | Реализует изменения по плану | Список изменённых файлов + краткое описание |
| 03 | 03-reviewer.md | Ревью кода на соответствие плану и качеству | VERDICT: PASS / FAIL + замечания |
| 04 | 04-validator.md | Прогоняет сборку и тесты | Статус сборки/тестов + логи ошибок |
